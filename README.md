# R5 Navegación [NavHost]

Aplicación Android de ejemplo desarrollada con Kotlin y Jetpack Compose.

## Funcionalidad
1. **Inicio:** el usuario captura nombre y edad.
2. **Perfil:** recibe nombre y edad mediante argumentos de una ruta de Navigation Compose.
3. **Confirmación:** muestra un mensaje final y permite volver al inicio.

## Abrir en Android Studio
1. Descomprime `R5NavegacionNavHost.zip`.
2. En Android Studio selecciona **Open** y elige la carpeta `R5NavegacionNavHost`.
3. Acepta la sincronización de Gradle y espera a que se descarguen las dependencias. Se necesita conexión a internet.
4. Selecciona un emulador (por ejemplo, Pixel) y pulsa **Run ▶**.

## Tecnologías
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose con `NavHost`, `composable`, `NavType` y `navArgument`

## Evidencias sugeridas
Toma capturas del emulador mostrando:
- Pantalla Inicio con los campos de nombre y edad.
- Pantalla Perfil con los datos recibidos.
- Pantalla Confirmación.
